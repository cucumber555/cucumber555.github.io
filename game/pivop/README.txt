PIVOP v5

이번 버전의 방향:
- Story Mode 이름을 Practice Mode(연습 모드)로 변경
- 메인 화면의 모든 주요 버튼 연결
- PvP는 플레이어가 없는 상태에서 가짜 경기를 시작하지 않음
- PvP는 현재 실제 온라인 서버가 없는 상태임을 명확하게 표시
- 연습 모드에서 WASD / Space / 마우스 시선 / Q / X / ←→ / E / 마우스 클릭 구현
- 연습 모드 목표 8명 처치 후 CLEAR 화면
- E: 총 발사
- 마우스 왼쪽 클릭: 근접 공격
- X: 아이템창
- Q: 1인칭/3인칭
- 방향키: 아이템 선택

중요:
현재 PvP의 실제 온라인 2:2 매칭/친구 방/실제 상대 동기화는 아직 백엔드가 연결되지 않은 상태입니다.
다음 단계에서 Supabase/WebSocket 등으로 실제 방과 플레이어 동기화를 구현해야 합니다.
